2. 上传文件

≤ chunkSize 用 uploadUrl 单请求直传（PUT，原始二进制 body）；否则按 chunkSize 切块，循环 PUT partUrl（n 从 1 开始），最后 POST completeUrl 并带 {"totalParts":N}。

PUT /api/v1/transfers/{id}/file?st=SENDER_TOKEN （小文件） PUT /api/v1/transfers/{id}/parts/1?st=SENDER_TOKEN （分块 1..N） POST /api/v1/transfers/{id}/complete?st=SENDER_TOKEN {"totalParts":3}

3. 接收方取件

GET /api/v1/transfers?code=7KQ2M9 → {kind:"relay"|"p2p", transfer:{…}} POST /api/v1/transfers/{id}/accept {"code":"7KQ2M9"} → {downloadToken, downloadUrl:"/api/v1/transfers/{id}/download?t=…", fileName, fileSize} GET /api/v1/transfers/{id}/download?t=… （文件流；流结束后云端副本自动删除）

4. 发送方管理

GET /api/v1/transfers/{id}/status?st=SENDER_TOKEN DELETE /api/v1/transfers/{id}?st=SENDER_TOKEN （撤销并立即删除）

5. P2P 信令（WebSocket）

先 POST /api/v1/p2p/rooms 取得 6 位配对码，再连接 GET /api/v1/signal?room=CODE&role=sender|receiver。信令只转发 JSON 文本，文件走 WebRTC DataChannel：

服务端 → 客户端：{"type":"peer-joined"} | {"type":"sdp","data":{…}} | {"type":"ice","data":{…}} | {"type":"peer-left"} | {"type":"pong"} 客户端 → 服务端：{"type":"sdp","data":{…}} | {"type":"ice","data":{…}} | {"type":"meta","fileName":…,"fileSize":…,"mime":…} （DataChannel 打开后由发送端同时发出） | {"type":"transfer-done"} | {"type":"ping"}

DataChannel 建议二进制分块 64KB、bufferedAmount 超过 4MB 时等待 bufferedamountlow 再继续；接收完成以文本消息 {"type":"file-end"} 收尾。

7. Android 接入示例（OkHttp）

// 创建任务 val body = """{"fileName":"$name","fileSize":$size,"mimeType":"$mime"}""" val res = client.newCall(Request.Builder() .url("$BASE/api/v1/transfers") .header("X-Api-Key", apiKey) .post(body.toRequestBody("application/json".toMediaType())) .build()).execute() // 分块上传（>8MB） file.inputStream().use { ins -> repeat(parts) { i -> val chunk = readChunk(ins, chunkSize) client.newCall(Request.Builder() .url("$BASE" + partUrl.replace("{n}", "${i + 1}")) .put(chunk.toRequestBody()) .build()).execute() } }

提示：P2P 模式在 Android 端可直接使用 org.webrtc（Google 官方 SDK）按上述信令协议实现；中转模式使用 OkHttp 流式下载即可，边下边写盘避免占用内存。

8. 端到端加密（AES-256-GCM）

创建任务时传 "encrypted": true：客户端先用随机 256 位密钥在本地加密，再上传密文。密钥仅存在于分享链接的 #k= 片段或「取件码-密钥」完整取件码中，永远不会发送到服务器；查询接口只返回 encrypted: true 标记。

密文容器格式 FDENC1： "FDENC1" ← 6 字节魔数 [4字节LE帧长][12字节IV][密文帧(含16字节GCM标签)] × N （帧长=密文字节数，不含IV） 帧 0 = 元数据 JSON {"n":文件名,"m":MIME,"s":大小} 帧 1..N = 4MB 内容分块；AAD = 帧序号（uint32 小端） 密钥 = AES-256-GCM 原始密钥，base64url 编码（43 字符）

Android 解密示例：Cipher.getInstance("AES/GCM/NoPadding") + GCMParameterSpec(128, iv)，doFinal 前调用 updateAAD(帧序号4字节小端)。接收流程不变：accept → download（得到密文流）→ 本地解析 FDENC1 逐帧解密。加密任务的 fileName 对服务器显示为占位符 encrypted.fdenc。
